## 三、反转确认数（reversal_count）对比分析

反转确认数决定「需要连续几根同向砖块才触发开仓/反转」：
- **rc=1**：每一根砖块即触发 → 交易频率最高，跟随市场最灵敏
- **rc=2**：连续 2 根同向砖块 → 传统 Renko 信号，平衡频率与过滤
- **rc=3**：连续 3 根同向砖块 → 最保守，过滤噪音强但信号少

| 指标 | rc=1 | rc=2 | rc=3 |
|---|---|---|---|
| 扫描组合数 | 72 | 72 | 72 |
| 日内 3-10 笔达标组合数 | **7** | 1 | 0 |
| 最高综合评分 | **87.3** | 75.5 | 75.2 |
| 平均最大回撤 | **7.96%** | 17.18% | 23.59% |
| 平均日内交易频率 | 1.6 | 1.2 | 1.1 |
| 最优组合 | 5m atr atr14x0.5 | 5m atr atr7x0.5 | 1h fixed fixed5 |

**结论**：对于日内 3-10 笔交易目标，**rc=1（每砖触发）配合适中砖块大小**是最优选择。
rc=2 频率明显下降（多数 2-3 笔/日），rc=3 则完全低于目标频率。

## 七、Profimr 挑战参数建议

### 挑战号（50K → 目标盈利 $3,000，EOD 回撤 ≤ $2,000）

推荐参数：**5m + ATR(14, 0.5) + rc=1**

| 每日目标 | 计算 | 说明 |
|---|---|---|
| 日均 6 笔交易 | 6 × avg_win | 在合成数据中平均每笔盈利 |
| $3,000 目标 | ~10-15 个交易日 | 日均盈利 $200+ |
| EOD 止损 | 已内置 `max_daily_loss=$2000` | 当日亏损达限停止开仓 |
| 仓位控制 | 30 张 × 0.5 ATR ≈ 10-25 点砖 × $2 | 每次反转最大亏损 = 砖块大小 × 30 × $2 |

**关键风险控制**：
1. ATR(14) 在 NQ 5m 周期约 15-40 点 → 砖块大小 = 7.5-20 点
2. 每次反转亏损最大 = 砖块大小 × 30 张 × $2 = 约 $450-$1,200/次
3. 当日累计亏损 $2,000 时自动停止（已在策略中实现）

### 出金号（连续 5 盈利日 × ≥$200/日）

推荐参数：**5m + ATR(14, 0.75) + rc=1**（回撤更小，稳定性更高）

## 八、重要声明

⚠️ **本回测使用合成 MNQ 数据（基于 NQ 统计特征的蒙特卡洛仿真）**

真实 MNQ 数据中会有：
- 隔夜跳空（CME Globex 夜盘数据）
- FOMC、CPI 等宏观事件冲击
- 流动性低点（开盘前 / 午休 / 收盘后）
- bid-ask spread = 0.25 点 tick = $0.50/张

**建议步骤**：
1. 通过 Sierra Chart、Rithmic、Tradovate 导出真实 MNQ 历史数据（OHLCV，5m/15m）
2. 替换 `data/raw/NQ_5m_*.csv`，重新运行 `python nq_backtest.py`
3. 对比真实数据与仿真数据结果差异，再决定实盘参数

## 九、参数文件配置

实盘/模拟交易时，在 `live_simulation.py` 中配置：

```python
from strategies.renko_reversal_strategy import RenkoReversalStrategy
from core.renko_builder import RenkoBuilder

# 推荐 #1 配置
builder = RenkoBuilder(method='atr', atr_period=14, atr_multiplier=0.5)
strategy = RenkoReversalStrategy(
    initial_capital=50_000.0,
    contract_multiplier=2.0,   # MNQ: $2/点
    max_contracts=30,          # 最大 30 张
    margin_per_contract=1_000.0,
    max_daily_loss=2_000.0,    # Profimr EOD 限制
    session_start_hour=13,     # UTC 13:30 = 9:30 ET
    session_end_hour=20,       # UTC 20:00 = 4:00 PM ET
    reversal_count=1,          # 每砖触发
)
```
