# MNQ Renko + SAR TradingView 指标

## 📖 概述

这是一个结合 Renko 砖型图和 Parabolic SAR 的趋势跟踪指标，专为 MNQ（Micro E-mini Nasdaq-100）期货设计，也适用于其他市场。

## 🎯 策略逻辑

### 入场条件
- **做多信号**: Renko 连续 2 个上涨砖块 + SAR 在价格下方（多头）
- **做空信号**: Renko 连续 2 个下跌砖块 + SAR 在价格上方（空头）

### 平仓条件
- SAR 方向反转
- Renko 砖块方向反转

## ⚙️ 最优参数设置

| 参数 | 最优值 | 说明 |
|------|--------|------|
| 砖块大小 | 8.0 点 | Renko砖块大小 |
| SAR初始AF | 0.02 | 加速因子起始值 |
| SAR步进AF | 0.02 | 加速因子增量 |
| SAR最大AF | 0.2 | 加速因子上限 |
| 确认砖块数 | 2 | 趋势确认所需砖块 |

## 🔧 安装步骤

### 方法1: 通过 Pine Editor 添加

1. 打开 [TradingView](https://www.tradingview.com/)
2. 点击图表底部的 **Pine Editor** 标签
3. 删除默认代码
4. 复制 `mnq_renko_sar_indicator.pine` 的全部内容并粘贴
5. 点击 **Add to Chart** 按钮
6. 指标将显示在图表上

### 方法2: 保存为指标

1. 按照方法1的步骤1-4
2. 点击 **Save** 按钮
3. 输入指标名称（如 "MNQ Renko+SAR"）
4. 在 **Indicators** 菜单的 **My Scripts** 中可随时加载

## 🔔 设置警报

### 创建警报步骤

1. 在图表上右键点击指标
2. 选择 **Add Alert on MNQ Renko + SAR 趋势指标...**
3. 选择警报条件：
   - **🟢 做多信号** - 入场做多提醒
   - **🔴 做空信号** - 入场做空提醒
   - **⚠️ 多头平仓** - 多头止损/止盈提醒
   - **⚠️ 空头平仓** - 空头止损/止盈提醒
   - **📢 所有交易信号** - 接收所有信号

4. 设置通知方式：
   - App 推送通知
   - 邮件
   - Webhook（用于自动化交易）
   - 弹窗/声音

### 警报消息示例

```
MNQ Renko+SAR: 做多信号! Renko趋势上涨 + SAR多头确认. 价格: 18500.25
```

## 🎛️ 参数调整建议

### 不同市场建议

| 市场 | 砖块大小 | 说明 |
|------|----------|------|
| MNQ | 8.0 点 | 微型纳指期货 |
| NQ | 20-30 点 | 标准纳指期货 |
| ES | 2-4 点 | 标普500期货 |
| MES | 1-2 点 | 微型标普期货 |
| MGC | 2-3 点 | 微型黄金期货 |
| BTC | 100-200 USD | 比特币 |

### 调参原则

1. **砖块太小**: 信号过多，噪音大，手续费高
2. **砖块太大**: 信号太少，入场滞后
3. **SAR 太敏感** (AF 大): 频繁止损
4. **SAR 太迟钝** (AF 小): 止损滞后
